# forge-foundry-claude

Forge Foundry engineering workbench, packaged as a **private** Claude Code plugin.
All 31 primitives as skills + a bundled deterministic Python engine.

**Status:** under construction. See `docs/superpowers/specs/` (design) and
`docs/superpowers/plans/` (implementation plan). Built by vendoring
[`forge-foundry-primitives`](https://github.com/arula-ai/forge-foundry-primitives) at a pinned tag.
